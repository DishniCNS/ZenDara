# Daralla

Daralla is an adaptive interface theme/mod for Zen Browser. It combines a compact, orientation-safe sidebar foundation with responsive Essentials, folder interactions, media cards, site-aware accents, split-view drop targets, configurable URL-bar placement, glass materials, density presets and Focus Mode.

## Included

- Compact left/right sidebar and floating compact-sidebar behavior
- Top/bottom URL-bar configuration
- Responsive Essentials tile treatment
- Folder styling and bounce behavior
- Media cards with artwork-derived glow and audio visualization
- Site-aware accent handling
- Split-view drag/drop zones and preview behavior
- Undo-close helper behavior
- Loading progress treatment
- Compact / Comfortable / Spacious density presets
- Unified glass material toggle
- Focus Mode

## Sine

The repository is laid out as a Zen/Sine mod. Publish the contents of this folder as a Git repository and use that repository URL in Sine's repository/custom-mod installer.

## Credits

Daralla is rebuilt from implementation foundations and interaction concepts from Wireframe 2.0 and Zia, under a single Daralla namespace and integration layer. Preserve upstream license and attribution requirements when publishing.
