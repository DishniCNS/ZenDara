# Daralla Changelog

## 0.2.0

- Added Daralla Command Center on Ctrl/Cmd+K.
- Added command and tab search in one palette.
- Added keyboard navigation: Arrow Up/Down, Enter and Escape.
- Preserved Wireframe compact-sidebar geometry when the sidebar is moved to the right.
- Added unified glass/material controls and density presets to the Daralla settings layer.
- Kept site-aware accent color, media card and split-view systems under the Daralla namespace.
